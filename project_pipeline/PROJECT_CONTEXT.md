# Project Context

## Project

Data Pipeline Monitoring and Recovery Framework

---

## Problem Statement

Organizations rely on automated ETL pipelines.

When pipelines fail due to API failures, missing files, database connectivity issues, or network interruptions, business reports become inaccurate.

The goal is to build a lightweight monitoring framework that detects these failures, logs execution metadata, retries recoverable failures, and visualizes pipeline health.

---

## Scope

This project will implement:

- CSV ETL Pipeline
- API ETL Pipeline
- Monitoring Framework
- Recovery Engine
- Execution Logging
- Data Freshness
- Streamlit Dashboard

---

## Target Users

- Data Engineers
- Students
- Organizations using ETL workflows

---

## Expected Outcome

A fully working framework capable of:

- Monitoring pipelines
- Detecting failures
- Recovering from temporary failures
- Displaying execution history
